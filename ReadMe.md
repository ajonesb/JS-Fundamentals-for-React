# JavaScript Fundamentals For React

![image](https://github.com/ajonesb/JS-Fundamentals-for-React/assets/17410649/b135b3ef-b568-46cd-9c12-8ea8ee871c4c)

## Project Overview

This project is designed to help beginners learn and experiment with core JavaScript concepts essential for modern web development, including those used in React applications. Each concept is isolated in its own folder containing executable JavaScript files (and it's own project with a ReadMe), allowing for focused learning and experimentation implemented with programming clean code principles such as SOLID, DRY, KISS.

## Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/): Node.js 12.x or later.

## Project Structure

The project is organized into folders, each dedicated to a specific JavaScript concept. Please go through the order from beginner to advanced topics in the following order:

1. data-types
2. functions
3. loops
4. conditional-rendering
5. switch-statements
6. template-literals
7. destructuring
8. event-listeners
9. DOM-manipulations
10. spread-and-rest
11. modules
12. fetch-API
13. promises-async-await
14. state-management

## Getting Started

To get a local copy up and running follow these simple steps.

**Clone the repository:**

```bash
git clone https://github.com/ajonesb/JS-Fundamentals-for-React.git
cd JS-Fundamentals-for-React
```

## How to Use:

- Open the file you want to run.
- Open the terminal in VS Code.
- Use the Node command to run the complete file, for example:
  `node 1-data-types/arrays/index.js`

## To run and modify any of these scripts:

- Follow the same steps as before to navigate to the relevant folder in the terminal and run the script using Node.js. For example here:
  `node promises-async-await/index.js`.

- This wuill run the exact file in that directory and output the results of the logic on file on the console. 

  ** IMPORTANT**

- The idea is to work with each code module step by step and not feel overwhelmed. This project is designed to be very clean, structured organized to teach the new developer how to create clean, readable, maintainable, structured code with various important clean code principles such as SOLID, DRY, KISS.

- Work one at a time with each module that has there own code blocks, run it on the terminal, understand it, change it, modify it, then if you fully understand and can create different modifications that you are sure off and don't have any doubts about the code, move on to the next.

## Some Additional Tips for getting the most out of this:

- KISS (Keep it Simple Stupid) - Do not saturate yourself! There is a lot of code but do it step by step!
- Look at every piece of code with a "program with logic, think about the logic you want to instruct the computer" approach.

- Code is poetry, read the code like poetry. After all, good code should be clean and when done right, it looks like poetry. This code is designed with that in mind. 

- Baby Steps! As mentioned previously, work in steps. Daily progress little by little is better than no progress nothing at all.

- When stuck, take breaks! if you get dizzy or get code overdose, take a break, close the pc, come back to it tomorrow, it will make more sense (after you put some time into it offcourse).

- Learn for yourself always, not others. The key here is to build a solid foundation and understanding of this programming language so you can then take the challenges of working as a developer.

Do not do it because "I need to become a developer asap or I need to work or bring in an income" approach, that is a concentration killer! Also do not do it for a company, do it because you wanna have confidence in what you are working with, a company will fire you whenever they want and will post the add on LinkedIn the very next day. Do it for you to feel confident.

- Experiment by modifying the code and observing the output, which will help solidify your understanding. The best way to learn is to get hands on practice. 

- This setup will not only help you learn JavaScript essentials but also prepare you for common React patterns and workflows as well as teach you how to read, create clean code which those same concepts you can implement in other programming languages.

- Take advantage of the learning experience instead of concentrating on the negative!

Read more here on how to solve a problen in Software Engineering: https://medium.com/@ajonesb/software-development-tips-on-how-to-solve-a-problem-6ab7a4df5bf7

- There may be times where you have to look at videos, documentation, articles related to help with the code. I recommend it. Please keep in mind however that there has to be a balance between learning theory and getting in there and getting practice working with the code. 

## WATCHOUT:
