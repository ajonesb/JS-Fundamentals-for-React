# JavaScript Event Listeners Fundamentals

This project is designed to help beginners learn the fundamental concepts of event listeners in JavaScript. Each event listener technique is modularized and explained with introductory and summary notes. Understanding these concepts is crucial for mastering JavaScript and transitioning to React.

## Why Learn These Concepts?

1. **Basic Event Handling**:
   - Learn to add and remove event listeners to handle user interactions.

2. **Event Propagation**:
   - Understand event bubbling and capturing to manage how events propagate through the DOM.

3. **Custom Events**:
   - Create and emit custom events for complex event-driven programming.

4. **Event Delegation**:
   - Efficiently handle events by utilizing a parent element to manage multiple child elements.

5. **Event Options**:
   - Use options like `once`, `passive`, and `capture` to customize event listener behavior.

## How to Use This Project

Each event listener technique is located in its own module within the `event-listeners` directory. The `index.js` file demonstrates how to instantiate and call these functions. Review the introductory and summary notes for each function to understand its purpose and usage.
