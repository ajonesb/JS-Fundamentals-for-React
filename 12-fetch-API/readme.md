# JavaScript Fetch API Fundamentals

This project is designed to help beginners learn the fundamental concepts of the Fetch API in JavaScript. Each technique is modularized and explained with introductory and summary notes. Understanding these concepts is crucial for mastering JavaScript and transitioning to React.

## Why Learn These Concepts?

1. **Making HTTP Requests**:
   - Learn to make GET, POST, PUT, and DELETE requests using the Fetch API.

2. **Handling Responses**:
   - Understand how to handle the data received from requests.

3. **Error Handling**:
   - Learn robust methods to deal with errors in network requests.

4. **Advanced Scenarios**:
   - Explore advanced uses of the Fetch API with query parameters, headers, and async/await.

## How to Use This Project

Each Fetch API technique is located in its own module within the `fetch-api` directory. The `index.js` file demonstrates how to instantiate and call these functions. Review the introductory and summary notes for each function to understand its purpose and usage.

Review each file, understand the Fetch API techniques and their usage, and experiment by modifying and running the code.
